# قائمة الاختبار الشاملة

ترتيب مقصود: الباك إند أولاً (بلا هاتف)، ثم السيناريوهات الكاملة من الطرفين.
كل بند هنا سلوك يجب أن تراه بعينك، لا مجرد «لا يوجد خطأ».

---

## ٠) آلي — قبل أي شيء

```bash
cd cigram-ads-system
./worker/test/run.sh /path/to/cigram-admin-worker-v2.js   # ٢٦٠ فحصاً
./tools/javac-check.sh user                               # ٢١٨ صنفاً
./tools/javac-check.sh admin                              # ٢٥٤ صنفاً
./user-app/test/run-ws-test.sh                            # ١٣ فحصاً لعميل WebSocket
```

- [ ] الأربعة تنجح بلا فشل واحد.

## ١) بعد نشر الـ Worker

```bash
API=https://cigram-admin-api.wwq-mixtv.workers.dev
TOKEN=<ADMIN_TOKEN>
curl -s $API/health | grep -c '"GET /ads"'              # 1
curl -s $API/movies | head -c 40                         # القديم يعمل
curl -s "$API/ads/config" | head -c 120
curl -s -X POST "$API/ads/quote" -H 'content-type: application/json' \
     -d '{"slot":"hero","days":30}'                      # total 7920 افتراضياً
curl -s "$API/admin/ads/security" -H "Authorization: Bearer $TOKEN"
```

- [ ] `/health` يسرد مسارات الإعلانات، والقديمة كلها باقية.
- [ ] `/admin/ads/security` يقول `key_configured: true`. لو `false` فـ
      `ADS_MEDIA_KEY` غير مضبوط — **أوقف واضبطه** قبل تجربة المحادثة.
- [ ] `GET /ads?slot=hero` يرد `{"ads":[]}` مع `server_time_ms`.

## ٢) السيناريوهات التي طلبتها

### ٢.١ حملة ليوم واحد
- [ ] أنشئ حملة `inline` تبدأ الآن وتنتهي بعد ٢٤ ساعة، وأضف مادة، واعتمدها.
- [ ] تظهر في التطبيق خلال ٥ دقائق (مدة الكاش) أو عند إعادة فتح الشاشة.
- [ ] غيّر `end_at` إلى ما قبل الآن: تختفي من `GET /ads` فوراً (بلا انتظار Cron).

### ٢.٢ حملة مجدولة
- [ ] حملة تبدأ بعد يومين، معتمدة.
- [ ] `GET /ads` لا يعيدها.
- [ ] في لوحة الأدمن حالتها «مجدولة».
- [ ] حرّك `start_at` إلى الماضي: تصبح «نشطة» وتظهر.

### ٢.٣ حملة منتهية
- [ ] حملة انتهت أمس، معتمدة.
- [ ] `GET /ads` لا يعيدها، ولوحة الأدمن تقول «منتهية».
- [ ] **اختبار الساعة**: قدّم ساعة الهاتف شهراً للأمام وأعد فتح التطبيق مع حملة
      نشطة ← **لا تختفي** (نستخدم وقت الخادم). أرجعها شهراً للخلف مع حملة منتهية
      ← **لا تظهر**.

### ٢.٤ تناوب معلنين
- [ ] حملتان في نفس المساحة بنفس الأولوية (٥)، معتمدتان.
- [ ] `GET /ads?slot=hero` يعيد الاثنتين.
- [ ] بدّل `did=` بين عشرة قيم: الأولى في الترتيب تتبدّل بينهما.
- [ ] نفس `did` مرتين متتاليتين: نفس الترتيب (لا وميض).
- [ ] اجعل أولوية واحدة ١٠ والأخرى ١: الأولى تتصدّر في الأغلبية الواضحة.

### ٢.٥ حصرية
- [ ] فعّل «حصرية» على إحدى الحملتين.
- [ ] `GET /ads` يعيد **واحدة فقط** هي الحصرية.
- [ ] أطفئ الحصرية: تعودان معاً.

### ٢.٦ استهداف مدينة
- [ ] حملة باستهداف «الرياض» فقط.
- [ ] `GET /ads?slot=...&city=الرياض` يعيدها.
- [ ] `...&city=جدة` لا يعيدها.
- [ ] بلا `city` لا يعيدها (الاستهداف المحدد لا يُخاطر).

### ٢.٧ استهداف نسخة التطبيق
- [ ] حملة بـ `min_app_version = 99.0.0`.
- [ ] لا تظهر في تطبيقك الحالي؛ أزل القيد ← تظهر.

### ٢.٨ انقطاع الإنترنت
- [ ] افتح «أعلن هنا» متصلاً ثم أطفئ الإنترنت وأعد فتحها:
      تفتح كاملة مع شريط «أنت تشاهد نسخة محفوظة».
- [ ] الحاسبة تُبقي آخر سعر محسوب وتقول إنه قديم، ولا تمسحه.
- [ ] في المحادثة: أرسل ٣ رسائل ← ساعة على كل واحدة، وشريط «لا يوجد اتصال».
- [ ] **أغلق التطبيق تماماً** ثم أعد فتحه متصلاً: الثلاث تُرسل بالترتيب، ولا
      تتكرر أي واحدة.
- [ ] الإعلانات المحفوظة تظهر بلا اتصال، والمنتهية منها لا تظهر.

### ٢.٩ كل أنواع الرسائل والوسائط
- [ ] نص عربي طويل (أكثر من ٣ أسطر).
- [ ] نص فيه `<` و`>`: يظهر كما كُتب.
- [ ] صورة من المعرض ← ضغط ← ظهور في الفقاعة ← اضغطها لتكبيرها.
- [ ] صورة بالكاميرا (مع رفض الإذن أولاً لرؤية الرسالة، ثم قبوله).
- [ ] فيديو ٣٠ ميجابايت: صورة مصغرة ومدة وشريط تقدم حقيقي.
- [ ] **اضغط «إلغاء» في منتصف رفع الفيديو**: يتوقف فعلاً، ولا يبقى ملف نصفي.
- [ ] فيديو أكبر من ٦٤ ميجابايت: رسالة واضحة بالحد، لا فشل صامت.
- [ ] تسجيل صوتي: اضغط مطولاً، الموجة تتحرك، ارفع ← يُرسل مع موجته.
- [ ] تسجيل ثم **اسحب للإلغاء**: يُلغى ويظهر تأكيد.
- [ ] تسجيل أقل من ثانية: رسالة «التسجيل قصير جداً».
- [ ] شغّل تسجيلاً وبدّل السرعة ١× → ١٫٥× → ٢×.
- [ ] ملف PDF: يُرفع، ويفتح **داخل التطبيق** بتنقّل صفحات.
- [ ] ملف غير مسموح (مثلاً `.apk` بتغيير الامتداد إلى `.pdf`): يُرفض بـ 415.
- [ ] بطاقة «طلب إعلان» من الحاسبة: كل الحقول صحيحة.
- [ ] بطاقة «عرض سعر» من الإدارة: المبلغ والمدة والملاحظة.

### ٢.١٠ متصل / غير متصل
- [ ] الأدمن «متصل»: رأس محادثة المعلن «متصل الآن» بنقطة خضراء.
- [ ] الأدمن يكتب: «يكتب الآن…» عند المعلن.
- [ ] الأدمن «خارج ساعات العمل»: يظهر ذلك + الرد التلقائي.
- [ ] **أغلق تطبيق الأدمن تماماً**: يصبح «غير متصل · آخر ظهور منذ …».
- [ ] انتقل في تطبيق الأدمن من الوارد إلى محادثة ورجوع: **لا** يتحول إلى
      غير متصل (مهلة الـ ٢٫٥ ثانية).
- [ ] المعلن يفتح المحادثة: الأدمن يرى «المعلن متصل الآن».

### ٢.١١ رفض حملة
- [ ] جرّب الرفض بلا سبب: **يُمنع** برسالة.
- [ ] ارفض بسبب «الصورة منخفضة الجودة».
- [ ] في «إعلاناتي» عند المعلن: الحالة «مرفوضة» **والسبب نصاً**.
- [ ] الحملة المرفوضة لا تظهر في `GET /ads` أبداً.

### ٢.١٢ تجديد
- [ ] من «إعلاناتي» اضغط «تجديد»: تفتح المحادثة وبطاقة طلب بنفس المساحة والمدة.
- [ ] من لوحة الأدمن: «تمديد الحملة» ٧ أيام على حملة منتهية ← تعود «نشطة».
- [ ] بعد التمديد يعود تنبيه «٣ أيام» للعمل عند قرب النهاية الجديدة.

### ٢.١٣ التقرير العام
- [ ] من تقرير حملة: انسخ الرابط وافتحه في متصفح (بلا تسجيل دخول).
- [ ] يعرض مشاهدات ونقرات ونسبة نقر ورسماً يومياً.
- [ ] **لا يعرض**: سعراً، حالة دفع، أسباب إبلاغ، أي بيانات مستخدمين.
- [ ] عدّل حرفاً في التوكن: 404.

## ٣) بوابة الموافقة والسياسات
- [ ] الزر السفلي في «أعلن هنا» رمادي ونصّه «اقرأ السياسات أولاً».
- [ ] اضغطه قبل الوصول للنهاية: ينزل بالصفحة ويشرح السبب.
- [ ] اضغط خانة الموافقة قبل النهاية: نفس السلوك.
- [ ] امسح لنهاية الصفحة ثم وافق: الزر يصبح أحمر ويفتح ورقة التواصل.
- [ ] أعد فتح الصفحة: الموافقة محفوظة.
- [ ] ارفع رقم نسخة السياسة من الأدمن: الموافقة تُلغى وتُطلب من جديد.

## ٤) عرض الإعلانات في التطبيق
- [ ] مكان بلا إعلان: يختفي تماماً، بلا فراغ ولا هامش.
- [ ] `hero` بحملتين: يتبدّل كل ٦ ثوانٍ مع نقاط.
- [ ] ضع إصبعك عليه: يتوقف؛ ارفعه: يعود.
- [ ] مرّر بسرعة فوق بطاقة `inline` دون توقف: **لا** تُحسب مشاهدة.
- [ ] اتركها ظاهرة ثانية: مشاهدة واحدة. اخرج وارجع في نفس اليوم: لا تتكرر.
- [ ] اضغط البطاقة: الإجراء يعمل، وتُحسب نقرة واحدة.
- [ ] إجراء «كوبون»: ينسخ ويظهر تأكيد.
- [ ] ⋮ ← «لا تظهر لي هذا»: تختفي فوراً ولا تعود.
- [ ] ⋮ ← «إبلاغ» بسبب: تختفي، **والمشاهدات لا تزيد**، والأدمن يرى الإبلاغ وسببه.
- [ ] `popup`: مرة واحدة يومياً فقط.
- [ ] `sticky`: أغلقه ولا يعود بقية اليوم.
- [ ] `splash`: عدّاد وزر تخطي يعمل من أول ثانية، ولا يؤخّر فتح التطبيق.
- [ ] كل شكل عليه علامة «إعلان» ظاهرة.

## ٥) قسم الحساب
- [ ] كل الصفوف بنفس الارتفاع والأيقونة والسهم والفواصل.
- [ ] كل صف قديم يفتح ما كان يفتحه (٦ صفوف).
- [ ] «أعلن هنا» آخر عنصر بشارة «جديد».
- [ ] كزائر: «الاعدادات» مخفي، ولا بطاقة فارغة.
- [ ] حجم خط النظام الأكبر: لا نص مقصوص ولا صف منهار.

## ٦) الأمان والخصوصية
- [ ] `GET /ads/chat/history` بلا رمز: 401.
- [ ] برمز معلن آخر: ترى محادثته هو فقط (اختبر بحسابين).
- [ ] أرفق `media_id` من محادثة أخرى: 403.
- [ ] افتح رابط وسائط موقّعاً بعد ١٠ دقائق: 403.
- [ ] عدّل حرفاً في `sig=`: 403.
- [ ] ملاحظة داخلية من الأدمن: غير موجودة في أي رد يصل للمعلن (افحص الشبكة).
- [ ] أرسل ٢٥ رسالة بسرعة من المعلن: يُوقف عند ٢٠ برسالة عربية، والأدمن غير محدود.
- [ ] «حذف بيانات الإعلانات» من حساب المعلن: المحادثة والوسائط تُحذف، ويقول
      صراحةً إن الحملات تبقى.
- [ ] احظر معلناً: لا يرسل، وأنت ترسل.

## ٧) المتانة
- [ ] دوّر الشاشة في كل شاشة جديدة: لا انهيار ولا فقدان حالة.
- [ ] اضغط رجوع أثناء رفع فيديو: لا انهيار، والرفع يُلغى.
- [ ] أغلق المحادثة أثناء تسجيل صوتي: الميكروفون يُحرَّر (لا تحذير نظام).
- [ ] شغّل على أندرويد ٧ (API 24) وأندرويد ١٤.
- [ ] الوضع الفاتح/الداكن في النظام: الشاشات داكنة دائماً كبقية التطبيق.
- [ ] TalkBack: كل زر وأيقونة لها وصف منطوق.
